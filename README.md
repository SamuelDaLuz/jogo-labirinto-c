🏦 [ Jogo de Labirinto em C ]

> Status do Projeto: 🏁 Concluído 

Um projeto divertido e funcional para testes com o objetivo de programar um jogoo de labirinto interativo com sistema de cores e sons.

---

## 🚀 Funcionalidades

- [x] Se mover no labirinto por meio das teclas: W-A-S-D
- [x] Sons específicos para movimentos certos, movimentos proibidos, e movimentos em armadilhas
- [x] Diversas cores para melhorar a esperiência do usuário e facilitar a distinção de cada elemento

---

## 🛠️ Tecnologias Utilizadas

- Linguagem: C
- IDE / Editor: Code Blocks
- Controle de Versão: GitHub

---

## 🛠️ Como Executar o Projeto

### Pré-requisitos
* Um compilador C instalado no seu computador (como o **GCC**, que faz parte do **MinGW** no Windows, ou nativo no Linux/macOS).
